# Migración: stock máximo y precio por ítem de inventario

El esquema base vive en [`../../../SQL/schema.sql`](../../../SQL/schema.sql), fuera
de este paquete (y los archivos `.sql` están además excluidos del control de
versiones de `HernandezLab-WEB` por convención — ver `.gitignore`). Este
documento registra en Markdown los cambios incrementales que ese esquema
necesita para soportar las funcionalidades agregadas en la web:

- **Stock máximo** por ítem de inventario, usado para la tabla de stock
  máximo y el aviso de "sobre stock" en el módulo de Inventario.
- **Precio** por ítem de inventario, usado por el módulo aparte de Precios.

Aplicar contra el proyecto de Supabase (SQL Editor o migración de
`supabase db`) antes de usar esas dos funcionalidades:

```sql
-- 1. Stock máximo por ítem de inventario (alertas de sobre-stock y
--    referencia para el módulo de compras).
alter table public.inventario
  add column if not exists stock_maximo integer;

alter table public.inventario
  add constraint inventario_stock_maximo_check
    check (stock_maximo is null or stock_maximo >= stock_minimo);

-- 2. Precio por ítem de inventario (consumido por el módulo aparte de
--    Precios, independiente de la gestión de stock).
alter table public.inventario
  add column if not exists precio numeric(10, 2);

alter table public.inventario
  add constraint inventario_precio_check
    check (precio is null or precio >= 0);
```

Una vez aplicada, sincronizar el mismo cambio en `../SQL/schema.sql` para
que quede como fuente de verdad del esquema completo.
